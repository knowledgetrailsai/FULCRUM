# Phase 4 — Pilot & Calibrate

`Home › 06-lifecycle › Phase 4`

[← Previous: Phase 3, Instrument](phase-3-instrument.md) · [Contents](../README.md) · [Next: Phase 5, Operate & Attribute →](phase-5-operate-attribute.md)

**Objective:** Validate that the projected Cost Density and Value Density from Phase 2 hold up in real usage, before scaling.

## Activities

1. Run a limited rollout (small user group, limited volume, or shadow mode alongside the existing process).
2. Compare **actual vs. projected** Cost Density and Value Density using the Phase 3 instrumentation.
3. Identify Value Leakage sources not anticipated in Phase 1 — see [Value Leakage](../03-value-economics/value-leakage.md).
4. Adjust routing, context design, and evaluation depth based on real iteration counts and outcome rates. Apply the [Optimization Levers](../05-architecture-and-design/optimization-levers.md) as needed.

## Exit Criteria

Actual Value Density within an agreed tolerance of the Phase 2 projection, **or** a documented remediation plan with a clear owner and timeline if it isn't.

## Owner

Product owner + engineering, jointly.

## Common Pitfalls

- Declaring the pilot successful based on functional performance alone, without checking density metrics against projection
- Treating a wide gap between projected and actual density as a reason to abandon measurement, rather than a reason to investigate which multiplier is driving it
- Scaling past this phase before Value Leakage sources are identified: leakage found after scale-up is far more expensive to fix

See the [worked example](../10-case-studies/customer-support-agent.md) for a concrete illustration of this phase in practice.
